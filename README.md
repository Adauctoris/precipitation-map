# precipitation-map
A small project that shows a precipitation map for various cities across the UK.

I built this project as over the summer of 2026, the UK experienced quite a few several heatwaves with a distinct lack of rain. Therefore, I was inspired to create this map. It takes the precipitation of the last few days and compares it to the UK’s daily average for that time. Areas that fall near the average are green while areas that don’t are yellow. It uses ‘open-meteo’ for precipitation and ‘folium’ for the map.

Development in progress – the documentation for ‘open-meteo’ was helpful when developing this project.
